# Функции вход и выход

> Источник: конспект без ссылки

## Конспект

Функция — это именованный кусок кода с входом и выходом.

- **Вход** — аргументы. Их задаёт вызывающий код.
- **Выход** — значение `return`. Если `return` нет, Python возвращает `None`.
- **Побочный эффект** — всё, что функция меняет снаружи: печать, файл, глобальная переменная.

Полезное правило для учёбы: сначала напиши функцию, которая только считает и возвращает результат. Печать оставь снаружи, в `if __name__ == "__main__"`.

Так задание проще проверять: можно вызвать функцию с разными аргументами и сравнить ответ, не читая вывод на экран.

Пример формы:

```python
def greet(name: str) -> str:
    return f"Привет, {name}"
```

`greet` не печатает. Она отдаёт строку. Это легче тестировать, чем `print` внутри.

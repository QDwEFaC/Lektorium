# Лекторий

Локальное веб-приложение: материал из URL (или вручную) становится markdown-заметкой в Obsidian, к лекции привязывается задание, для задания заводится папка кода для Zed.

Базы данных нет: всё лежит в файлах репозитория.

```
URL / конспект  →  vault/Лекции/<предмет>/<модуль>/*.md
                    ↓ wiki-ссылка [[Лекции/предмет/модуль/…]]
                  vault/Задания/*.md
                    ↓ путь code/...
                  code/<номер>-<тема>/
```

## Возможности

- Иерархия **предмет → модуль → лекция**, оглавление на странице предмета и содержание по заголовкам на странице лекции.
- Сохранение материала: вставь текст вручную или, если у себя подключён локальный модуль разбора, передай URL / сохранённый HTML.
- Разбор чужих страниц в продукт не входит: контракт входа и выхода — `src/lib/page-parse/`, код — у каждого свой в `impl.local/` (в git его нет).
- Wiki-ссылки `[[Лекции/…]]` и `[[Задания/…]]` кликабельны в приложении и в Obsidian.
- Картинки рядом с заметкой (`01 — Название/Вложения/`) и запасной каталог `vault/Вложения/`.
- Формулы LaTeX: `$строчные$` и `$$выносные$$`.
- Синтаксис плагина [Extended Markdown Syntax](https://github.com/kotaindah55/extended-markdown-syntax) (`:::класс`, `!!{класс}текст!!`, `++`, `==` и др.) плюс CSS-сниппеты из `vault/.obsidian/snippets/`.
- Задания со статусами и папки кода для Zed.

## Запуск

Нужны Node.js 22+ и npm.

```bash
npm install
npm run dev
```

Приложение: [http://127.0.0.1:4521](http://127.0.0.1:4521).

Прод-сборка:

```bash
npm run build
npm run start
```

Опционально systemd пользователя: скопируй [`deploy/lektorium.service`](deploy/lektorium.service) в `~/.config/systemd/user/`, поправь `WorkingDirectory`, затем:

```bash
systemctl --user daemon-reload
systemctl --user enable --now lektorium
```

После правок кода: `npm run build && systemctl --user restart lektorium`. Заметки в `vault/` подхватываются без пересборки.

Открыть в браузере из терминала: `xdg-open http://127.0.0.1:4521`.

## Obsidian

1. Open folder as vault → папка `vault/` (не корень репозитория).
2. Открой `00 Главная` и `Карта курса`.
3. Graph view: предметы, модули, лекции и задания разного цвета по полю `type` в frontmatter.

Wiki-ссылки вида `[[Лекции/Лекторий/Старт/01 — …]]` кликабельны.

Картинки клади в папку рядом с заметкой:

```
vault/Лекции/<предмет>/<модуль>/01 — Название.md
vault/Лекции/<предмет>/<модуль>/01 — Название/Вложения/схема.png
```

В тексте:

```markdown
![[схема.png]]
![Схема](01 — Название/Вложения/схема.png)
```

Вставка из буфера в Obsidian может уйти в `vault/Вложения/` (`attachmentFolderPath`). Приложение ищет файл сначала рядом с лекцией, потом там.

Стили блоков: сниппет `vault/.obsidian/snippets/my-fmt.css` (включён в настройках внешнего вида) и классы вроде `:::my-blue-block`.

Конспект можно вставить вручную. Вкладки «Из URL» и «HTML целиком» вызывают локальный модуль разбора, если он есть (`src/lib/page-parse/impl.local/`). Без него форма всё равно сохраняет заметку с текстом, который ты ввёл.

## Zed

1. File → Open → корень этого репозитория.
2. Код заданий — в `code/`. В каждой папке есть `ЗАДАНИЕ.md` и `README.md` со ссылками на заметки.
3. Задачи редактора: `.zed/tasks.json` (запуск Лектория и пример `greet`).

Не правь заметки курса в Zed, если уже открыл их в Obsidian. В Zed — `code/`.

## Локальные данные

В репозитории — обучающий предмет **Лекторий** (модули Старт и Примеры, три задания в `code/`). Свои конспекты, картинки и другие предметы в git не попадают.

После клона открой `vault/` как vault в Obsidian: шаблоны, плагин и пример курса уже на месте.

## Структура

```
vault/                 ← Obsidian vault
  .obsidian/           ← настройки, плагин, сниппеты
  Лекции/Лекторий/     ← пример курса (в git)
  Лекции/<своё>/       ← остальные предметы (gitignore)
  Задания/             ← три учебных задания в git, остальные нет
  Вложения/            ← запасной каталог картинок (gitignore)
  Шаблоны/
code/                  ← три учебных папки в git, остальные нет
src/                   ← приложение (Next.js)
  lib/page-parse/      ← вход/выход разбора страниц; impl.local/ не в git
deploy/                ← пример systemd user unit
.zed/                  ← настройки Zed
```

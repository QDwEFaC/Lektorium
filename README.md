# Лекторий

Учебный vault: материал из URL становится markdown-заметкой в Obsidian, к лекции привязывается задание, для задания заводится папка кода, которую открывают в Zed.

## Как это связано

```
URL / конспект  →  vault/Лекции/*.md     (Obsidian)
                    ↓ wiki-ссылка [[Лекции/...]]
                  vault/Задания/*.md     (Obsidian)
                    ↓ путь code/...
                  code/<номер>-<тема>/    (Zed)
```

Приложение пишет те же файлы, которые ты видишь в редакторах. Базы данных нет.

## Запуск

```bash
npm install
npm run dev
```

Приложение: [http://127.0.0.1:4521](http://127.0.0.1:4521).

## Obsidian

1. Open folder as vault → папка `vault/` (не корень репозитория).
2. Открой `00 Главная` и `Карта курса`.
3. Graph view: лекции и задания разного цвета по полю `type` в frontmatter.

Новые лекции из URL появляются в `vault/Лекции`. Wiki-ссылки вида `[[Лекции/01 — …]]` и `[[Задания/01 — …]]` кликабельны.

Если страница не открывается (видео, PDF, закрытый курс), вставь заголовок и текст вручную — карточка лекции всё равно сохранится.

## Zed

1. File → Open → корень этого репозитория.
2. Код заданий — в `code/`. В каждой папке есть `ЗАДАНИЕ.md` и `README.md` со ссылками на заметки.
3. Задачи редактора: `.zed/tasks.json` (запуск Лектория и пример `greet`).

Не правь заметки курса в Zed, если уже открыл их в Obsidian: будет путаница с вики-ссылками. В Zed — `code/`.

## Что уже лежит в курсе

- Лекция «Как учиться в Лектории» и задание сохранить первую ссылку.
- Лекция «Функции вход и выход» и задание написать `greet` в Python.

Сохрани свою лекцию из URL, создай к ней задание — появятся новая заметка и новая папка кода.

## Структура

```
vault/                 ← Obsidian vault
  Лекции/
  Задания/
  Шаблоны/
  Карта курса.md
code/                  ← проекты для Zed
src/                   ← само приложение Лекторий
.zed/                  ← настройки Zed
```

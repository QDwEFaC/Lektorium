# Написать greet

В `main.py` напиши функцию `greet(name: str) -> str`, которая возвращает строку вида `Привет, Маша`.

Не вызывай `print` внутри `greet`. Печать — только в `solve()` или в блоке `if __name__ == "__main__"`.

Проверь три имени, в том числе пустую строку: реши, что функция должна вернуть в этом случае, и запиши решение в комментарии.

# Сохранить первую лекцию

Эта папка — место для кода в **Zed**. Заметки живут в Obsidian.

- Лекция: `vault/Лекции/Лекторий/Старт/01 — Как учиться в Лектории.md`
- Задание: `vault/Задания/01 — Сохранить первую лекцию.md`
- Язык: python

## Как работать

1. В Zed открой корень репозитория (или сразу эту папку).
2. Само задание — сохранить лекцию из URL в Лектории, не писать код.
3. Когда закончишь, в Лектории поставь статус «Сдано».
